# إعلان ListGo — وايت بورد + 2D أنيميشن

فيديو إعلان طولي (1080×1920، مناسب لريلز وتيك توك وستوري) لموقع [listgo.shop](https://listgo.shop):
رسم بالقلم على سبورة بيضاء، وشخصيات 2D، وتعليق صوتي بصوت راجل مصري (Gemini TTS، الصوت `Charon`).

| الملف | الوصف |
|---|---|
| `scenes.json` | سكريبت التعليق الصوتي بالعامية المصرية + الكابشن، ووصف أسلوب الصوت |
| `tts.py` | يولّد الصوت مشهد بمشهد من Gemini TTS ويكتب `timings.js` (توقيت كل مشهد = طول الجملة) |
| `animation.html` | الأنيميشن نفسه (SVG): محرّك الرسم بالقلم وإيد الماركر، والـ 8 مشاهد |
| `render.mjs` | يصوّر الأنيميشن فريم بفريم بـ Playwright ويطلع MP4 بالصوت عن طريق ffmpeg |
| `out/listgo-ad.mp4` | الفيديو النهائي |

## إعادة التوليد

```bash
# 1) الصوت (المفتاح من متغير بيئة فقط، ممكن أكتر من مفتاح بفاصلة)
GOOGLE_API_KEY=... python3 tts.py        # أو: python3 tts.py --no-audio  لمعاينة صامتة
# 2) الفيديو
node render.mjs out/listgo-ad.mp4
```

- لمعاينة سريعة في المتصفح: `python3 -m http.server` وافتح `animation.html` واضغط play.
- لتعديل الكلام: عدّل `vo` (اللي بيتقري) و`caption` (اللي بيظهر مكتوب) في `scenes.json` وشغّل الخطوتين.
  الصوت متخزّن لكل مشهد، فاللي ماتغيّرش مش بيتولّد تاني.
- صورة ثابتة لأي لحظة: `node render.mjs --still 12.5 frame.png`
